Matrix Studio — mobile UI mockups

A mobile-first redesign that keeps the whole feature set and the current dark "control room" palette. At phone width each view has one column, a bottom tab bar, and bottom sheets for detail (dossier, asides, fork). Past 768px the same parts spread into columns (see the tablet frame at the end). Sample content is invented.

One column, three tabs per runLive view becomes Conversation / Cast / Analysis rather than a 320px sidebar beside the feed.
Bottom sheets, not side drawersDossier, Asides, Fork and Export slide up and can be dismissed with a swipe; the feed stays visible behind them.
The form becomes a wizardThe 1,800-line New Run form splits into five steps with a sticky cost forecast and one "Next" button in reach of the thumb.
Header actions go in a ⋯ menuStop stays visible while a run is going; Brief, Export, Model and Scrubber move into an overflow menu.
Hints are tapped, not hoveredEvery title= tooltip becomes an ⓘ tap target, because phones have no hover.
44px minimum targetsChips and toggles get bigger hit areas; the scrubber knob gets a thumb-sized handle with haptic ticks at each turn.
