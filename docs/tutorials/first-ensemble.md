# Your first ensemble

One conversation gives you one answer, and the same setup run again can end differently. An ensemble runs the same setup several times and counts which conclusions held in every run and which turned up only once.

In this tutorial you run the conversation from [Your first conversation](first-conversation.md) three times and read the report. Do that tutorial first: this one starts from its run.

It takes about 20 minutes, most of it waiting. It costs roughly three times what your first conversation cost, plus a little for the report.

## Part 1: Start from your first run's setup

1. On the **Runs** screen, click your first run's card. It is the one without a **Branch** tag.

   The run opens, with **✓ Complete** under its codename.

2. Click the **⋯** button at the top right, then **Start fresh from this setup**.

   The new-run wizard opens, titled **New run from a setup**. A note says "Prefilled from" your run's codename. The topic is filled in, **Max messages** is 6 and **Generate avatars** is unticked.

3. Tick **Closing round when the ceiling is reached**.

   The setup doesn't carry this setting over, so you set it again. The report reads the closing statements just as the single run did.

4. In **Run**, choose **Several times — same brief, then a report**.

   A **How many times** box appears, set to 5. Below it, a line reads "5 conversations, each up to 6 turns. Nothing differs between them."

5. Change **How many times** to `3`.

   The line now reads "3 conversations, each up to 6 turns."

## Part 2: Launch it

1. Click **Next: Cast**.

   Maya, Alex and Jordan are all there, as you left them.

2. Click **Next: Knowledge**, **Next: Assume** and **Next: Launch**.

   Under **Topic**, **Type** reads "ensemble · 3 runs". The button at the bottom now reads **▶ Run 3 simulations**, so you can see how many runs you are paying for before you press it.

3. Click **▶ Run 3 simulations**.

   The ensemble page opens. It shows:

   - **Groups:** "base — 3 runs", with "nothing varied". All three runs are copies, so they form one group.
   - **Conversations (0 of 3 finished):** three runs named after the ensemble, ending `-base1`, `-base2` and `-base3`, each "running".
   - **Report:** "Waiting for 3 conversations to finish."

## Part 3: Read the report

1. Wait. The page updates by itself.

   The three conversations run side by side. When all three have finished, the report starts building. It can take several minutes, and you don't need to keep the page open while it does.

2. When the report appears, read **What the runs concluded**.

   It lists the conclusions that two or more runs reached. If no conclusion turned up twice, it says so: the runs diverged, and that is the result.

3. Read **What held, by group**.

   Each row is one demand or refusal a persona held, such as a condition Maya set. The **base** column says how many of the three runs it appeared in, for example "3 of 3" or "1 of 3".

4. Read **Across the conversations**, and the notes below it.

   This is a written comparison of the three runs. The notes below it say what the counts can support. With three runs, they tell you whether something held in every run, in some, or in only one, and nothing finer.

5. Click one of the conversation names under **Conversations**.

   It opens as an ordinary run, with the conversation, cast and analysis you met in the first tutorial. Use the browser's back button to return to the ensemble.

You can find the ensemble again from the **Ensembles** tab in the dock, or in the **Ensembles** section at the top of the **Runs** screen.
