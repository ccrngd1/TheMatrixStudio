# How to fork a run with a different assumption

Fork a run at the turn an assumption was made, with that assumption replaced or withdrawn, so you can compare the two conversations.

A fork is one more draw. To measure what an assumption was worth over several runs per value, run an ensemble instead ([How to run an ensemble](run-an-ensemble.md), "a different working assumption").

## Prerequisites

- Matrix Studio open and signed in.
- A run that is no longer generating and has at least one working assumption, set before the run or made by the moderator ([How to set working assumptions and scheduled messages](set-assumptions-and-scheduled-messages.md)).
- Budget for the fork: everything after the assumption's turn is generated again, so an assumption set before the run means a whole new conversation.

## Fork from the assumption's card

1. Open the run and find the assumption's **ASSUMES** card in the conversation.
2. Tap **Fork with a different assumption**.
3. Edit the value in the box, for example from "about 60 people" to "about 15 people".

   The note under it gives the fork's cost.

4. Tap **Fork from turn N**, or **Withdraw it instead** to fork without the assumption at all. **Cancel** closes the editor.

## Fork from the scrubber, at a later turn

Use this when you want everything up to a later turn to stay as it was.

1. Open the scrubber (**Scrub**, or **⋯** then **Scrub and branch**).
2. Move to the turn to fork from. Only assumptions in force at that turn are offered.
3. Under **Change at this turn**, choose **Change an assumption** or **Withdraw an assumption**.
4. Pick the assumption, and for a change type the new value and an optional basis.
5. Tap **Branch with change**. It stays disabled while the new value equals the old one.

What was said before the fork turn under the old value is kept.

## Check it worked

- The new run opens, with a **From** chip in its header back to the original. A fork made from the card also has a description naming the change ("A1: … → …", or "A1 withdrawn at turn N").
- For a change, the new run's **ASSUMES** card reads "replaced at turn N (was: …)".
- Compare the two runs' summaries, or their decision briefs, side by side.
