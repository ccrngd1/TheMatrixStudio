# How to hide and show runs

Take conversations out of your Runs list without deleting them, and put them back.

A hidden run still opens from a link, stays in its ensemble, and its cost still counts towards any monthly budget. Hiding is per run; ensembles cannot be hidden.

## Prerequisites

- Matrix Studio open and signed in.

## Hide a run

From the Runs list:

1. On the Runs screen, find the run's card.
2. Tap the crossed-out eye at the card's top-right corner (its label is "Hide" and the run's name).

   The card leaves the list at once. If the server refuses, it comes back with a red message saying why.

From the run itself:

1. Open the run and tap **⋯** in the header.
2. Choose **Hide from the Runs list**.

   The header shows a **Hidden** tag while you are on the run.

Runs inside an ensemble are hidden the same way: unfold the ensemble on the Runs screen with the arrow on its card, then use the eye on the member's card.

## Find and show a hidden run

1. On the Runs screen, tap the **Hidden (N)** chip under the search box. It appears only when at least one run is hidden.

   The list now shows hidden runs only, as one flat list, with a note saying so. Search works within it.

2. Tap the eye on the run's card to show it again, or open the run and choose **⋯** then **Show in the Runs list**.
3. Tap **Hidden (N)** again to return to the normal list.

## Check it worked

The **Live now**, **Finished** and **Spend · 7 days** figures at the top of the Runs screen count only the runs in view, so they change as you hide and show runs. The **Hidden** chip's count goes up or down by one each time.
