# How to ask an aside

Ask a question about a finished run, of the analyst, one persona in character, the whole room or a consultant, in a private side-thread that does not change the run.

## Prerequisites

- Matrix Studio open and signed in.
- A run that has ended with a transcript: **Complete**, **Stopped** or **Capped**.
- Each reply is a model call.

## Steps

1. Open the run.
2. Tap **Asides** below the conversation, or **⋯** in the header and then **Asides**.
3. Under **New aside**, choose who to ask:
   - **Analyst (about the whole run)**
   - **A persona (in character)**, then pick the persona
   - **The room (all personas)**
   - **A consultant (answers from its sources)**, then pick the consultant (offered only when the run has consultants)
4. Tap **Start**.
5. Type the question in **Ask a follow-up…** and tap **Send** (or press Enter).

   "writing a reply…" shows while the reply is generated. It can take a minute or two.

6. Ask follow-ups in the same thread. To change the model for replies, pick one under **Model** above the question box.

To return to the list of threads, tap **← All threads**. Each thread shows its message count and cost.

## If no reply arrives

The thread keeps your question and says that no reply arrived; send it again to retry. A reply that took too long is reported as stopped, with nothing saved. A narrower question is quicker to answer.

## Bring a reply into the conversation

1. Under the reply, tap **bring into conversation**.

   This creates a new branch from the run's last turn with the reply added as a turn, and the group carries on from there. It costs the new turns. The original run is not changed.

2. The branch opens. See [How to branch a run from a turn](branch-a-run.md) for what a branch is.

## Check it worked

The thread lists your question and the reply, marked "aside". The run's transcript, summary and cost are unchanged: asides are analysis, not part of the conversation.
