# Studies: pre-registered comparisons and evaluations

Measurements made to decide a default or test a claim. Most are pre-registered: the criteria were
committed before any run, and results were appended afterwards without editing them. Each records
its design, its criteria, the result, and any decision that followed.

- [SPEAKER-SELECTION-EVALUATION.md](SPEAKER-SELECTION-EVALUATION.md): what is wrong with next-speaker selection, and the interventions measured to fix it; A+B were adopted.
- [SELECTION-MODEL-DEFAULT.md](SELECTION-MODEL-DEFAULT.md): whether speaker selection should default to a bigger model. It should not.
- [EMBEDDING-DIMENSION-MEASUREMENT.md](EMBEDDING-DIMENSION-MEASUREMENT.md): embedding width of 256, 512 or 1024 measured for the AWS vector indexes; 1024 was chosen.
- [CITE-INLINE.md](CITE-INLINE.md): asking personas to cite passages inline, with two comparisons and the operator's decision to turn it on.
- [EVIDENCE-LEAN.md](EVIDENCE-LEAN.md): a best guess and a current lean with every evidence request, the first comparison.
- [EVIDENCE-LEAN-2.md](EVIDENCE-LEAN-2.md): the second evidence-lean comparison, scored by lean, after which it became the default.
- [EVIDENCE-LEAN-3.md](EVIDENCE-LEAN-3.md): evidence lean on a second, different brief.
- [EVIDENCE-LEAN-FOLDING.md](EVIDENCE-LEAN-FOLDING.md): whether evidence lean makes personas give up a firm position before its stated condition is met.
- [CAPITULATION-STUDY.md](CAPITULATION-STUDY.md): whether converged research runs settled the question or folded.
- [MODERATOR-ASSUMPTIONS.md](MODERATOR-ASSUMPTIONS.md): working assumptions added by the moderator, measured, plus three classifier attempts.
- [ASSUMPTION-ENSEMBLE.md](ASSUMPTION-ENSEMBLE.md): what one working assumption is worth, run as the only difference between two ensemble groups.
- [JUDGE-VARIANCE.md](JUDGE-VARIANCE.md): how much the blind judge varies when it scores the same transcript repeatedly.
- [ESCALATION-STUDY.md](ESCALATION-STUDY.md): whether cognition lets a persona escalate rather than fold.
