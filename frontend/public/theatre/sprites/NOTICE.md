# Sprite artwork

`char*.png` and `emotes.png` are copied unmodified from the 8-Bit Agents activation demo, which is
licensed under the Apache License, Version 2.0 — the same licence as this project (see `LICENSE`
at the repository root).

Each character sheet is 4 frames × 8 rows of 48 px: rows 0–3 idle facing down, right, up and
left; rows 4–7 walking in the same order. `emotes.png` is 8 × 4 cells of 16 px.

Deliberately not copied from the source set: `char17` and `char23` (six-row sheets with broken
walk cycles), sheets depicting real, identifiable people, a character resembling a third party's
trademarked mascot, and vehicle and scenery sprites the theatre has no use for.
